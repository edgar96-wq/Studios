# Studios

- `crew-studio-android/` — Crew Studio, the field app for survey crews (Android). Every push builds `CrewStudio.apk` and publishes it under Releases.
- `ledger-studio-android/` — Ledger Studio, mileage tracking and books for the sole proprietorship (Android). Every push builds `LedgerStudio.apk` and publishes it under Releases as "Ledger Studio build N".
